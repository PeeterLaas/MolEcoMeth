# Seminar slides

Put your presentation here as a pull request. Accepted formats: `.pdf`,
`.pptx`, `.qmd` (and `.key`, `.odp` if that is what you have).

Name the file `githubusername-shortpapertitle.pdf`, and add that same file name
to your row in `../registrations.csv` in the same pull request.

Files in this folder are linked for download from the seminar page. They are
deliberately **not** rendered by the site: the course website will not execute
code that arrives by pull request.
